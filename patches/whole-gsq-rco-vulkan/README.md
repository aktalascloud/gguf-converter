# Whole-checkpoint GSQ/RCO on Vulkan

The calibration manifest accepts a matching single file or sharded Safetensors reference and recorded inputs for up to 512 tensors. A Vulkan shader searches a global byte budget using held-out projection errors. A second pass refines every output row in the selected layouts. Standard GGUF formats include Q4_1 and 32-aligned narrow matrices.

The benchmark uses the installed inference kernels and preserves model profiles. Projection losses describe the calibration signal. See the separate render results for throughput and output behavior. [GSQ](https://arxiv.org/abs/2604.18556) · [RCO](https://arxiv.org/abs/2605.00649)
